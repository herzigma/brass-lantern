# First benchmark results (2026-11-13)

The first real runs of Brass Lantern 0.2 against Grue 2.0. Nine models were run through OpenRouter on four games.
Total spend was **$7.86**, which includes pilot runs. The full tables are in [2026-11-13/](2026-11-13/).

## Setup

- **Agent:** default Brass Lantern settings. The model sees the last 30 turns verbatim and gets no notes scratchpad.
  Temperature is 0.7, `--reasoning low`, and the per-run turn limit is 150.
- **Games:**
  - `lantern-lane` and `skerrin-light` are the two original, memorization-free games.
  - `lost-pig` is a 2007 classic (7 points).
  - `zork1` is Zork I (350 points). It is heavily memorized.
- **Runs per cell:** budget models ran each game once and Skerrin Light 3 times. Frontier models ran each original
  game once.
- **Score:** the final in-game score divided by the game's maximum. For how errors and missing scores are counted,
  see the formula at the top of each leaderboard.

## What we learned

1. **The harness separates models.**
   - **Lantern Lane** is a smoke test: every working model wins it in about 30 turns.
   - **Skerrin Light** spreads scores from 1 to 50.
   - **Zork I** compresses everything into 11-15%, and its early points are the ones every walkthrough lists. That
     makes it a poor signal and a memorization risk. The original games are the better benchmark.
2. **Skerrin Light is fair but turn-limited at 150.** GPT-6.1 Sol solved it, and Gemini 4 Argon and Claude Sonnet 5.5
   were still scoring in their last five turns. Stalled models were stuck on different puzzles, so no single puzzle
   is an unfair bottleneck. **Run Skerrin Light at its suggested 300-turn limit** (omit `--max-turns`, or pass 300).
3. **Variance is real.** Gemini 3.5 Flash Lite scored 23, 30 and 41 across three runs. Use `--runs 3` or more before
   drawing conclusions about adjacent models.
4. **Output-format discipline is part of the test.** DeepSeek V4 Flash keeps writing after its command: it invents
   the game's reply on the same line ("look in barrelYou can't see any such thing") and echoes the status footer.
   That produced 64% invalid commands. The parser now ignores echoed footers and takes the last `>` on a line, which
   fixed the cases it can. What remains is a real failure to follow the format. Qwen 3.8 Flash also often omits the
   `> COMMAND` line; the one-shot format repair recovers those turns, and the leaderboard shows the rate.
5. **Cost per point varies about 50x.** GLM 5.3 Flash played 4 games for $0.04 and Gemini 4 Argon spent $1.80 on 2.
   GPT-6.1 Sol was the strongest and mid-priced.

## Reproduce

```bash
# Grue
cd grue && npm install && npm run setup && npm start
# Brass Lantern (OPENROUTER_API_KEY in .env)
python -m brass_lantern bench --games lantern-lane,skerrin-light --runs 3 --reasoning low \
  --models openrouter:openai/gpt-6.1-sol,openrouter:anthropic/claude-haiku-5.5 --max-cost-per-run 2
```

The raw per-run `run.json` and `transcript.jsonl` files are kept locally under `runs/`, which git ignores.
